# **App Name**: Lingkod-Ani: Smart Farming Platform

## Core Features:

- SMS Crop Reporting: Farmers submit crop reports via SMS, parsed for key info.
- AI Advisory Generation: AI generates farming advice based on incoming SMS reports. The LLM may use a knowledge base tool when deciding if and how to respond.
- Admin Validation Workflow: Barangay admins validate and approve AI-generated advice before sending to farmers.
- Farmer Registry and Profiles: Management of farmer profiles with crop data, SMS history, location mapping and risk scoring.
- Live SMS Mission Feed: A live feed displaying incoming farmer messages with urgency indicators and actions.
- Disaster Mode Dashboard: Emergency response dashboard for priority SMS, alerts, and resource monitoring.
- Reports and Analytics: NASA-level Reports with issue trend graphs, SMS volume charts, advice success rates.

## Style Guidelines:

- Primary color: Deep teal (#16A38F) evokes growth, nature, and a forward-thinking government initiative.
- Background color: Light green (#E2F9F4), desaturated tint of the primary color, provides a calm backdrop for detailed dashboards.
- Accent color: Muted turquoise (#48BFE3) to complement the teal with a modern touch.
- Body and headline font: 'Inter' a neutral grotesque-style sans-serif for both headings and body, since detailed information needs to be conveyed without stylistic distraction.
- Use clean, geometric icons that relate to farming, crops, and data visualization; integrate action-based shortcut icons.
- Employ a card-based design with soft, rounded components and clear sections for the dashboard.
- Subtle animations and smooth transitions for interactive UX; hover effects on cards; loading indicators; expand and collapse sidebar and header components.
